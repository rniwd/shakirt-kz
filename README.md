# shakirt.kz 🪁

Интерактивті тақтаға арналған сайт: **Ойындар** (Арқан тарту, Кезекпен, Туды тап, Жұпты тап), **Материалдар** және **Тесттер**. Бейнесабақтар — әзірлену үстінде. Туды көрсету үшін интернет керек (flagcdn.com).
Пәндер: математика, ағылшын тілі. Сервер, сборка, тіркелу қажет емес — таза HTML/CSS/JS.

## Жергілікті ашу
`index.html` файлын браузерде ашыңыз (немесе `python3 -m http.server`).

## GitHub Pages-ке жариялау (тегін)
```bash
cd "gulsara apai"
git init -b main
git add . && git commit -m "Алғашқы нұсқа"
git remote add origin https://github.com/<логин>/<репо>.git
git push -u origin main
```
Содан соң GitHub → репо → **Settings → Pages → Deploy from a branch → main / (root)**.
Сайт `https://<логин>.github.io/<репо>/` мекенжайында ашылады.

## Мұғалім қалай материал қосады
1. «Материалдар» → «👩‍🏫 Мұғалім режимі» → форма арқылы материал/тапсырма қосады (осы браузерде сақталады).
2. Барлық құрылғыда көрінуі үшін: «⬇ Жүктеп алу» → JSON-дағы деректерді `data/materials.js` және `data/questions.js` ішіне қосып, GitHub-қа жүктейді.

## GitHub лимиті
Репо ~1 ГБ дейін, Pages сайты ~1 ГБ. Ауыр файлдарды (видео, PDF) репоға салмай, Google Drive/YouTube сілтемесімен қосыңыз. Суреттер — ≤ 300 КБ.
